☕ Jornada Java

Este espaço foi criado para documentar e compartilhar a minha evolução no aprendizado da linguagem Java. Aqui você encontrará desde exercícios focados em lógica de programação até pequenos projetos estruturados, servindo como meu portfólio prático e ambiente de experimentação.

🎯 Objetivo

O principal objetivo deste repositório é consolidar o aprendizado construído tanto no campo acadêmico como pessoal através da prática, registrando a aplicação de conceitos fundamentais da engenharia de software, arquitetura de sistemas e frameworks do ecossistema Java.

📚 Conceitos e Tecnologias Exploradas

Ao longo desta jornada, os códigos e projetos aqui desenvolvidos abordam os seguintes temas:

Lógica de Programação: Exercícios práticos, algoritmos e resolução de problemas.

Programação Orientada a Objetos (POO): Classes, objetos, herança, polimorfismo, encapsulamento e abstração.

Estruturas de Dados: Uso avançado de Collections (Lists, Sets, Maps) e Generics para criação de códigos seguros e reutilizáveis.

Gerenciamento de Memória: Testes e estudos sobre o comportamento do Garbage Collector (GC) na JVM.

Interface Gráfica (GUI): Criação de aplicações desktop utilizando bibliotecas nativas do Java (como Swing ou JavaFX).

Padrões de Arquitetura: Estruturação de projetos utilizando o padrão MVC (Model-View-Controller).

Banco de Dados e CRUD: Operações de Criação, Leitura, Atualização e Deleção integrando o Java com bancos de dados.

Spring Boot: Desenvolvimento de aplicações web e APIs RESTful modernas, explorando injeção de dependências e mapeamento objeto-relacional.


🛠️ Ferramentas Utilizadas

Linguagem: Java (JDK versão 17)

Frameworks: Spring Boot

IDE: IntelliJ IDEA 

Gerenciador de Dependências: Maven
